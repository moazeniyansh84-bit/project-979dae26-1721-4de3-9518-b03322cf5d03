# تک شاخ کیدز

یک فروشگاه اینترنتی فارسی و راست‌چین با نام «تک شاخ کیدز» بساز. طراحی مینیمال، سبک، شیک و کودکانه باشد و از تصاویر پیوست به‌عنوان لوگو/هویت بصری و بنرهای اولیه استفاده کن. فروشگاه برای لباس کودک و نوجوان، کیف، کش مو و اکسسوری باشد. Lovable Cloud را برای پنل مدیریت، ورود مدیر، مدیریت دسته‌بندی و محصول، آپلود عکس محصول و ذخیره‌سازی داده‌ها فعال کن. بخش فروشگاه با صفحه اصلی، دسته‌بندی‌ها، جست‌وجو، فیلتر (دسته، سن، جنسیت، سایز، بازه قیمت)، صفحه محصول، سبد خرید، پیشنهادهای ویژه و کالاهای تخفیف‌دار داشته باشد. پنل مدیریت ساده و امن برای افزودن/ویرایش/حذف محصول، قیمت، تخفیف، موجودی و تصاویر بساز. محتوا و قیمت‌های نمونه فارسی باشد و تجربه موبایل عالی باشد.
